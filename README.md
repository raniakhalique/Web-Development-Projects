# Web Development Projects

A collection of responsive front-end projects built with HTML, CSS, and JavaScript, sharing a consistent dark, soft-UI design style.

## Projects

### 1. Calculator

A soft-UI calculator with floating 3D-style spheres, a light/dark theme toggle, and full keyboard support. Handles chained operations, decimals, sign toggle, delete, and divide-by-zero errors.

**Live demo:** https://raniakhalique.github.io/Web-Development-Projects/calculator/

### 2. To-Do App (Daylist)

A task manager where you can add, complete, and delete tasks, filter by All / Active / Done, and see a live count of remaining tasks. Includes smooth animations and an empty state.

**Live demo:** https://raniakhalique.github.io/Web-Development-Projects/todo-app/

### 3. Login & Sign-Up Page (Aurora)

A combined login and sign-up form with client-side validation, email format checks, a password strength meter, show/hide password toggle, and success states. This is a front-end demo with no backend.

**Live demo:** https://raniakhalique.github.io/Web-Development-Projects/login-auth/

### 4. Tribute Page (Ada Lovelace)

A tribute page to Ada Lovelace with a hero section, biography, timeline, and quote block, using a responsive editorial layout.

**Live demo:** https://raniakhalique.github.io/Web-Development-Projects/tribute-page/

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, animations, responsive media queries)
- Vanilla JavaScript (DOM manipulation, event handling, form validation)

## Run Locally

1. Clone the repository: `git clone https://github.com/raniakhalique/Web-Development-Projects.git`
2. Open any project's `index.html` in your browser.
